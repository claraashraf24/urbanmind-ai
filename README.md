# UrbanMind AI

UrbanMind AI is an AI-powered urban intelligence command center for monitoring city risk, simulated alerts, and real-time emergency activity across Toronto.

## Current MVP

- Real-time city dashboard
- Interactive Toronto map
- Live alert feed
- WebSocket-based alert updates
- Urban Risk Index
- Critical alert tracking
- Dominant category detection
- City status calculation
- Severity and category filters

## Tech Stack

### Frontend
- Next.js
- TypeScript
- Tailwind CSS
- Leaflet
- WebSockets

### Backend
- FastAPI
- Python
- WebSocket alerts
- Simulated urban risk engine
